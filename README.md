# Advantech WISE Devices System Log Analyzer

A web-based tool for parsing, visualizing, and analyzing system logs generated by Advantech WISE series IoT devices. It turns raw JSON log exports into a searchable table with a density timeline, letting engineers quickly spot patterns, errors, and connection events without reading raw hex by hand.

**Live app:** https://jim6501.github.io/Advantech-WISE-Devices-System-Log-Analyzer/

## Key Features

- **Smart auto-detection** of product series (Wi-Fi, LoRaWAN, NB-IoT, LAN) from the log's device UID.
- **Dedicated parsers** per protocol, decoding raw Payload Events (PE) into human-readable descriptions.
- **Density timeline** — visualizes event distribution over time; drag to select and zoom into a time range, click a dot to jump to that row in the table.
- **Virtualized log table** with search, event-type filtering, and CSV export.
- **Multi-file sessions** — load and switch between several log files at once.
- **Light/dark theme.**

## Development

The app lives in [`webapp/`](webapp) (React + TypeScript + Vite).

```bash
cd webapp
npm install
npm run dev      # start the dev server
npm run build    # production build -> webapp/dist
npm test         # run the unit tests (vitest)
```

`npm run build` produces a single self-contained `webapp/dist/index.html` (all JS/CSS inlined), so it also works when opened directly from disk without a server.

## Deployment

Pushing to `main` with changes under `webapp/` triggers [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml), which builds the app and publishes it to GitHub Pages automatically — no manual build/upload step needed.
